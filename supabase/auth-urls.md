# Supabase Auth URLs (one-time)

In [Authentication → URL Configuration](https://supabase.com/dashboard/project/vhoamzowtnwscfwirpvq/auth/url-configuration):

| Field | Value |
|-------|--------|
| **Site URL** | `https://saikat-pa.github.io/seu-student-portal/` |
| **Redirect URLs** | `https://saikat-pa.github.io/seu-student-portal/**` |

For local dev, also add:

- `http://localhost:3000/**`
- `http://127.0.0.1:3000/**`

Optional: **Authentication → Providers → Email** → turn **Confirm email** OFF so students can register and sign in immediately.
